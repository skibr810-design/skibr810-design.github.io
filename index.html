دليل أوامر Termux

التثبيت والأوامر الأساسية – Nmap في Termux

يُعد Nmap أحد أقوى أدوات فحص الشبكات، ويُستخدم لاكتشاف الأجهزة والمنافذ المفتوحة والخدمات على الشبكة. يُسهّل Termux تثبيت Nmap على هاتفك الذي يعمل بنظام Android، مما يُمكّنك من إجراء اختبارات الشبكة تماماً كما تفعل على نظام Linux. فيما يلي خطوات التثبيت والأوامر الأساسية.

تثبيت

قم بتحديث حزم Termux الخاصة بك أولاً:

pkg update && pkg upgrade -y

قم بتثبيت Nmap:

pkg install nmap -y

تحقق من إصدار Nmap:

nmap --version

مسح سريع للهدف:

nmap scanme.nmap.org

الأوامر الأساسية

مسح عنوان IP أو موقع ويب:

nmap target-ip-or-domain

مسح منفذ محدد:

nmap -p 80 target

مسح منافذ متعددة:

nmap -p 80,443,8080 target

مسح جميع المنافذ (1–65535):

nmap -p- target

الكشف عن الخدمة/الإصدار:

nmap -sV target

فحص نظام التشغيل:

nmap -O target

فحص شامل (معلومات تفصيلية):

nmap -A target

حفظ نتائج الفحص في ملف:

nmap target -oN output.txt

قم بإلغاء تثبيت Nmap:

pkg uninstall nmap
